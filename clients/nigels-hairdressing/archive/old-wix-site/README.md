# Original Wix site (archived)

A snapshot of Nigel's original Wix site at www.nigelshairdressingwiganandrochdale.com,
captured on 8 October 2026 just before the domain moved to the new build. Kept for the
before/after on cgdesignaus.com.

| File | What it is |
|---|---|
| `index.html` | Open this to view the old site. It shows the full-page screenshots and works offline, forever. |
| `desktop-full.png` | Full-page screenshot at 1440px wide |
| `mobile-full.png` | Full-page screenshot on a phone (360px wide) |
| `wix-original.html` | The page's raw HTML as Wix served it. It loads Wix's scripts and images from Wix's servers, so it may stop rendering once the Wix site is cancelled. Use the screenshots for display. |
| `content.md` | All the old site's text, including the old prices |

Web-ready before/after images for the CG Design site are in `public/previews/` at the
repo root: `nigels-before.webp`, `nigels-before-mobile.webp`, `nigels-after.webp` and
`nigels-after-mobile.webp`.
